# stress_code
This repository contains the code used for fMRI data preprocessing based on fMRIPrep, including preprocessing workflow configuration and execution scripts. It also provides scripts for dynamic functional connectivity analysis, including sliding-window-based connectivity estimation, K-means clustering, and optimal parameter evaluation. In addition, the repository includes R-based Elastic-net modelling scripts, code for mapping r values onto distinct striatal subregions, and scripts for visualizing correlation matrices as heatmaps. For the HMM analysis, mask-generation scripts and the main code for calling the HMM package are provided. The HMM-MAR package is not included and should be downloaded separately from GitHub: https://github.com/OHBA-analysis/HMM-MAR
.
